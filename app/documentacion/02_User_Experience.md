# 02 · User Experience

## Diseñando emociones

### Aurora

Version 1.0

---

# Introducción

Aurora no diseña pantallas.

Diseña momentos.

El objetivo del producto no consiste en mostrar información.

Consiste en acompañar emocionalmente al usuario durante todo el ciclo del viaje.

Antes.

Durante.

Después.

Y muchos años más tarde.

Cada interacción debe tener una intención emocional.

Nada aparece por casualidad.

Nada está colocado únicamente porque "queda bonito".

Todo debe provocar algo.

---

# La curva emocional

Todo viaje posee una curva emocional.

Aurora debe acompañarla.

Nunca romperla.

Nunca acelerarla.

Nunca forzarla.

Debe sentirse natural.

```

```

          ❤️

        Nostalgia
            ▲
            │
            │
            │
      Aventura
            ▲
            │
            │
      Ilusión
            ▲
            │

Preparación

```

---

# Primer contacto

El usuario abre Aurora.

No debe sentir que abrió una aplicación.

Debe sentir que abrió un regalo.

No mostrar inmediatamente botones.

No mostrar inmediatamente listas.

No mostrar inmediatamente tarjetas.

Primero.

Respirar.

Mucho espacio.

Una frase.

Una fotografía.

Una pequeña animación.

Después recién comenzar.

---

# El silencio también comunica

Aurora no debe intentar llenar todos los espacios.

Debe existir silencio visual.

Espacios grandes.

Fotografías enormes.

Textos cortos.

Nada debe sentirse apresurado.

---

# Antes del viaje

Estado emocional esperado.

```

😄

Tengo muchas ganas de viajar.

```

La aplicación debe responder.

```

Nosotros también.

Comencemos poco a poco.

```

---

# Cuenta regresiva

No debe sentirse como una bomba de tiempo.

Debe sentirse como un calendario de ilusión.

Cada día que falta.

Una frase distinta.

Ejemplos.

"Falta poco para escribir una nueva historia."

"Cada día estamos más cerca."

"No olvides dejar espacio para los recuerdos."

---

# El usuario jamás debe sentirse presionado

No queremos.

"Te faltan 9 actividades."

Queremos.

"Todo listo para mañana ❤️"

---

# El primer día

Cuando el usuario abre el Día 1.

No mostrar el itinerario inmediatamente.

Primero.

Pantalla completa.

Una fotografía.

Una frase.

```

Buenos días.

Hoy comienza una nueva aventura.

No sabemos cuál será el mejor recuerdo del día.

Pero estamos seguros de que alguno aparecerá.

```

Luego.

Botón.

✨ Comenzar.

---

# El viaje nunca debe sentirse como una carrera

Jamás mostrar.

40%

60%

80%

No queremos productividad.

Queremos recuerdos.

---

# Rituales

Aurora debe tener pequeños rituales.

Cada mañana.

Abrir un capítulo.

Cada noche.

Cerrar un capítulo.

Eso genera una conexión emocional.

---

# Descubrimiento

Cada día debe sentirse nuevo.

Aunque el usuario conozca Buenos Aires.

La aplicación debe transmitir.

Hoy todavía quedan cosas por descubrir.

---

# Días bloqueados

Nunca utilizar.

Acceso denegado.

Error.

Bloqueado.

No permitido.

Siempre utilizar mensajes positivos.

Ejemplo.

```

Todavía no.

Primero disfrutemos el día de hoy.

```

---

# Fotografías

No queremos almacenar imágenes.

Queremos capturar recuerdos.

Por eso.

Cada fotografía debe invitar al usuario a recordar.

No solamente a subir archivos.

---

# Videos

Los videos nunca deben mostrarse automáticamente.

Primero.

Una fotografía.

Después.

El usuario decide reproducir.

Queremos que la expectativa exista.

---

# Notas

Las notas son probablemente el elemento más valioso.

Una fotografía muestra.

Una nota explica.

Una emoción permanece.

---

# Favoritos

No utilizar estrellas.

No utilizar corazones grandes.

Solo un pequeño detalle.

Como guardar un recuerdo especial.

---

# Finalizar el día

Esta interacción es extremadamente importante.

No es un botón.

Es cerrar un capítulo.

Debe sentirse como cerrar un libro.

Con una animación lenta.

Con música opcional.

Con una pequeña reflexión.

Nunca simplemente desaparecer.

---

# Dormir también forma parte del viaje

Después de finalizar el día.

Aurora desaparece.

No intenta mantener al usuario dentro.

No muestra publicidad.

No recomienda cosas.

Solo dice.

```

Descansen.

Mañana escribiremos una nueva página.

```

Y termina.

---

# El cumpleaños

Este día rompe todas las reglas.

Ya no hay itinerario.

No hay horarios.

No hay mapas.

Solo emociones.

Toda la interfaz cambia.

Más cálida.

Más luminosa.

Más limpia.

El protagonista deja de ser Buenos Aires.

Ahora la protagonista es Kari.

---

# El final

El usuario espera terminar una aplicación.

Nosotros queremos comenzar un recuerdo.

Por eso.

Nunca utilizar.

"Fin."

En cambio.

Utilizar.

```

Nos volveremos a encontrar.

```

---

# Un año después

Esta interacción es probablemente la más importante de toda Aurora.

La aplicación debe decir.

```

Hace exactamente un año comenzó esta aventura.

¿Te gustaría volver a vivirla?

```

Nada más.

No mostrar botones gigantes.

No mostrar estadísticas.

Primero.

El recuerdo.

Después.

La aplicación.

---

# Nuestra obsesión

No queremos que el usuario piense.

"Qué bonita aplicación."

Queremos que piense.

```

Qué bonito viaje.

```

Si logramos eso.

Todo el trabajo habrá valido la pena.

---

# El principio más importante

Aurora no intenta que el usuario pase más tiempo dentro de la aplicación.

Aurora intenta que el tiempo que pase dentro sea inolvidable.

Esa diferencia cambia absolutamente todas las decisiones del producto.
```
