# 03 · Design Principles

Version 1.0

---

# Introducción

Aurora no tiene usuarios.

Tiene viajeros.

No tiene clientes.

Tiene personas que están viviendo un momento importante.

Cada decisión de diseño debe recordar eso.

---

# Primer principio

Las emociones siempre tienen prioridad sobre la información.

Si debemos elegir entre:

Mostrar más datos

o

Provocar una emoción.

Siempre elegimos la emoción.

---

# Segundo principio

Nunca hacer sentir que el usuario está utilizando software.

La tecnología debe desaparecer.

La historia debe permanecer.

---

# Tercer principio

Cada pantalla debe respirar.

Aurora ama el espacio vacío.

No llenar.

No saturar.

No intentar impresionar.

La elegancia vive en el espacio.

---

# Cuarto principio

Las fotografías cuentan la historia.

La interfaz solo las acompaña.

Nunca competir con ellas.

---

# Quinto principio

El usuario nunca debe sentir presión.

No usamos:

⚠

URGENTE

Nunca.

No usamos:

ERROR

Nunca.

No usamos:

NO PERMITIDO

Nunca.

Todo debe sentirse amable.

---

# Sexto principio

No existen archivos.

Existen recuerdos.

No existen imágenes.

Existen momentos.

No existen videos.

Existen historias.

No existen colecciones.

Existen aventuras.

---

# Séptimo principio

Cada animación debe tener una razón.

Nunca animar por animar.

Las animaciones son respiraciones.

---

# Octavo principio

No interrumpir.

Aurora jamás debe interrumpir un momento importante.

Jamás mostrar popups innecesarios.

Jamás pedir reviews.

Jamás pedir cinco estrellas.

El viaje es primero.

La aplicación después.

---

# Noveno principio

La aplicación nunca debe intentar ser el centro de atención.

Debe desaparecer.

El protagonista siempre es el viaje.

---

# Décimo principio

Todo debe sentirse hecho con cariño.

No perfecto.

Con cariño.

Existe una enorme diferencia.
