# 09 · Storytelling

## Designing Memories Instead of Screens

Version 1.0

---

# Introducción

Aurora no organiza un viaje.

Aurora cuenta una historia.

El usuario no debe sentir que navega entre pantallas.

Debe sentir que pasa las páginas de un libro.

Cada pantalla representa una página.

Cada día representa un capítulo.

Cada recuerdo representa una escena.

Nunca debemos romper esa ilusión.

---

# La narrativa

Toda historia tiene un ritmo.

Aurora también.

No existe información mostrada al azar.

Todo aparece exactamente cuando debe aparecer.

No antes.

No después.

# Las fotografías

No deben sentirse obligatorias.

Cada fotografía sugerida debe responder.

¿Por qué este recuerdo podría ser importante dentro de diez años?

Si no existe respuesta.

Eliminar esa fotografía sugerida.

---

# Los videos

No queremos muchos.

Queremos pocos.

Pero memorables.

Aurora sugerirá.

"Quizás este sea un bonito momento para grabar unos segundos."

Nunca más.

---

# Las notas

Las notas son probablemente el elemento más importante de todo el producto.

Una fotografía responde.

¿Qué vimos?

Una nota responde.

¿Qué sentimos?

# El verdadero protagonista

Buenos Aires no es el protagonista.

La guía tampoco.

El protagonista siempre será la historia que Camilo y Kari escriban juntos.

Si alguna pantalla hace que el usuario mire más la aplicación que la ciudad.

Esa pantalla está mal diseñada.

---

# Última regla

Aurora nunca cuenta un viaje.

Aurora ayuda a recordarlo.

Existe una diferencia enorme.

Y esa diferencia define absolutamente todo el producto.
