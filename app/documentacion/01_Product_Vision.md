# 01 · Product Vision

## Aurora

### Every Journey Deserves To Be Remembered

Version: 1.0

---

# Introducción

Aurora no nació para resolver un problema técnico.

Nació para resolver un problema emocional.

Hoy existen cientos de aplicaciones capaces de planificar un viaje.

Existen aplicaciones que muestran mapas.

Aplicaciones para comprar vuelos.

Aplicaciones para reservar hoteles.

Aplicaciones para compartir fotografías.

Aplicaciones para organizar gastos.

Sin embargo...

Cuando un viaje termina...

Todas esas aplicaciones dejan de tener sentido.

Los mapas ya no importan.

Los vuelos ya fueron utilizados.

Las reservas desaparecen.

Los itinerarios dejan de abrirse.

Las fotografías terminan olvidadas dentro de una carpeta llamada:

DCIM

o

IMG_20260718.jpg

Aurora quiere cambiar exactamente eso.

---

# Nuestra visión

No queremos crear la mejor aplicación para viajar.

Queremos crear la mejor aplicación para recordar.

Queremos que un viaje no termine cuando el avión aterrice.

Queremos que continúe viviendo durante años.

Queremos que cada fotografía tenga contexto.

Que cada restaurante tenga una historia.

Que cada video tenga una emoción.

Que cada nota vuelva a transportar al usuario exactamente a ese instante.

---

# El viaje no es el producto

Esta frase debe acompañar siempre al equipo.

El viaje NO es el producto.

El recuerdo sí.

Si una funcionalidad mejora el viaje pero no mejora el recuerdo...

Debe cuestionarse.

Si una funcionalidad mejora el recuerdo...

Probablemente pertenece a Aurora.

---

# Nuestra misión

Ayudar a las personas a conservar los momentos importantes de su vida de una forma organizada, emocional y hermosa.

No queremos almacenar archivos.

Queremos conservar historias.

---

# Nuestra promesa

Dentro de diez años...

Un usuario debería abrir Aurora.

Seleccionar un viaje.

Y sentir exactamente lo mismo que sintió cuando estuvo allí.

Si logramos eso...

El producto habrá cumplido su misión.

---

# ¿Qué hace diferente a Aurora?

Aurora no comienza cuando el usuario instala la aplicación.

Aurora comienza mucho antes.

Empieza con la ilusión.

Continúa con la aventura.

Y termina convirtiéndose en nostalgia.

Ese ciclo completo es el verdadero producto.

No una pantalla.

No una funcionalidad.

Todo el ciclo.

---

# Los tres actos de Aurora

## Acto I

La Ilusión

El usuario todavía no viaja.

Pero ya sueña con hacerlo.

La aplicación debe transmitir calma.

Emoción.

Expectativa.

Nunca ansiedad.

Nunca presión.

---

## Acto II

La Aventura

Ahora el viaje ocurre.

Cada día es un capítulo.

Cada lugar es un descubrimiento.

Cada fotografía empieza a construir un recuerdo.

El usuario nunca debe sentir que está utilizando una aplicación.

Debe sentir que está viviendo una historia.

---

## Acto III

El Recuerdo

Aquí ocurre la verdadera magia.

La aplicación deja de planificar.

Empieza a recordar.

Las fotografías ocupan el centro.

Las notas cobran valor.

Los mapas ahora muestran lugares donde ya estuvieron.

El viaje ya terminó.

Pero la historia continúa.

---

# El cuarto acto

Existe un cuarto acto.

Uno que ninguna aplicación tradicional tiene.

El aniversario.

Cada año.

La aplicación debe recordar.

No como una notificación cualquiera.

Sino como un pequeño regalo.

"Hace exactamente un año comenzó esta aventura."

Ese mensaje debe emocionar.

Nunca molestar.

---

# Qué NO queremos construir

No queremos una agenda.

No queremos una checklist gigante.

No queremos una red social.

No queremos otra aplicación para guardar fotos.

No queremos un Google Photos.

No queremos un Polarsteps.

No queremos competir con Notion.

No queremos reemplazar Google Maps.

---

# Lo que sí queremos construir

Queremos un libro.

Uno que se escriba solo.

Queremos un diario.

Uno que combine fotografías, lugares, videos y emociones.

Queremos un recuerdo.

Uno que pueda abrirse dentro de veinte años.

---

# El usuario ideal

No pensamos en millones de usuarios.

Pensamos en una pareja.

En una familia.

En un grupo de amigos.

Personas que entienden que algunos viajes cambian la vida.

No importa cuántos viajes hagan.

Importa que algunos nunca se olviden.

Aurora existe para esos viajes.

---

# Emociones que queremos provocar

Antes del viaje:

• Ilusión

• Curiosidad

• Expectativa

Durante el viaje:

• Descubrimiento

• Diversión

• Asombro

• Romanticismo

Después del viaje:

• Nostalgia

• Gratitud

• Orgullo

• Felicidad

Cada pantalla debe responder a una de esas emociones.

Si no transmite ninguna...

Debe replantearse.

---

# Filosofía de diseño

Toda decisión debe responder una única pregunta.

"¿Esto ayuda a recordar mejor?"

Si la respuesta es no.

No pertenece al producto.

---

# El efecto Aurora

Queremos que ocurra algo muy específico.

El usuario abre la aplicación.

Todavía no toca ningún botón.

Todavía no hace nada.

Y ya sonríe.

Ese instante.

Ese pequeño momento.

Es el verdadero éxito del producto.

---

# Una frase para todo el equipo

No desarrollamos software.

Construimos recuerdos.

Y los recuerdos son demasiado importantes como para tratarlos como simples datos.
