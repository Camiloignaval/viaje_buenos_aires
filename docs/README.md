# Documentación oficial de Aurora

**Estado:** punto de entrada oficial  
**Versión:** 1.0.0

Antes de proponer o implementar cualquier cambio, humanos e IAs deben leer esta documentación y actuar conforme a ella.

`README_FOR_AI.md` existe como acceso rápido para agentes de IA, pero no reemplaza esta lectura.

## Regla máxima

> Aurora no se mide por las funciones que tiene.  
> Aurora se mide por lo que hace sentir.

## Proceso obligatorio

Antes de cualquier cambio:

1. Auditar el estado actual.
2. Explicar qué rompe o qué riesgo introduce.
3. Contrastar con la Constitución.
4. Diseñar la solución que mejor preserve la experiencia.
5. Implementar solo si hace Aurora más memorable.

Si existe duda razonable, se conserva la experiencia actual.

## Etapa 2

Durante Etapa 2, Aurora no se optimiza para tener más funciones.

Se optimiza para que Buenos Aires 2026 quede como la primera historia completa, pulida y memorable de Aurora.

Todo lo que pertenezca a Etapa 3 o posteriores debe ir a Parking Lot.
