# Changelog de documentación Aurora

Todo cambio relevante en la documentación oficial de `docs/` debe registrarse acá.

La documentación sigue versionado semántico simple:

- `MAJOR`: cambia filosofía, autoridad o reglas base.
- `MINOR`: agrega documentos, secciones o criterios sin cambiar filosofía.
- `PATCH`: corrige redacción, enlaces, orden o mantenimiento.

## v1.0.0 — 2026-07-09

Versión inicial de la documentación oficial de Aurora Etapa 2.

### Agregado

- `00_AURORA_CONSTITUTION.md` como autoridad máxima de filosofía e identidad.
- `01_WORKFLOW.md` como protocolo obligatorio de trabajo.
- `02_PRINCIPLES.md` como criterios de decisión y cinco pilares.
- `03_AI_GUIDE.md` como guía para agentes de IA.
- `README_FOR_AI.md` como acceso rápido para IAs.
- `README.md` como punto de entrada único para humanos e IAs.
- `CHANGELOG.md` como historial centralizado.

### Decisión

La Constitución prevalece sobre cualquier otro documento, patrón técnico, buena práctica genérica o recomendación de implementación.

### Nota

Esta versión no cambia la filosofía de Aurora: la consolida, ordena y vuelve navegable dentro del proyecto.
